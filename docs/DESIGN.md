# 디자인 토큰

> 방향: **어두운 작업실형**(디자인 시안 B). 지금은 어두운 테마만 쓴다. 색은 반드시 아래 토큰(CSS 변수)으로만 쓰고 색 값을 코드에 직접 적지 않는다. 밝은 테마는 나중에 토큰 값만 한 벌 더 정의하면 된다(BACKLOG). 실제 정의는 `apps/web/src/app/globals.css`에 있다. 2026-10-11 디자인 리뷰로 토큰을 기본값 → 의미 → 부품 세 단으로 나눴다(M6).

## 원칙

- 청록(`--accent`)은 **선택·포커스·주요 버튼·실행 중·지나간 연결선**에만 쓴다. 노드 종류 표시, 성공, 정보 글자에는 쓰지 않는다.
- 상태는 항상 글리프와 함께 보여 준다: ✓ 성공, ▲ 경고, ! 오류, ● 실행 중, – 건너뜀. 색에만 기대지 않는다.
- `/10` 같은 투명도 색을 클래스에서 만들지 않는다. 옅은 색이 필요하면 `-soft` 토큰을 쓴다.
- shadcn 부품이 쓰는 이름(`--primary`, `--input`, `--ring` 등)은 아래 의미 토큰을 가리키는 별칭으로만 둔다.

## 사이드바

`components/app-sidebar`. 라우트 그룹 `(app)`의 모든 화면(목록, 에디터, 실행 기록, 실행 상세, 모든 실행, 설정)에 있고 로그인·벤치에는 없다. 화면 사이 이동은 사이드바가 맡는다.

| 항목 | 규칙 |
|---|---|
| 폭 | 펼침 240px, 접힘 56px. `--surface` 바탕, 오른쪽 `--border-subtle` |
| 구성 | 머리(로고 칩 22px · Nodeloom · 접기 «/»), 워크플로우 찾기(높이 32, ⌘K), 전체 워크플로우 · 모든 실행(최근 24시간 실패가 있으면 danger 배지), "워크플로우" 트리(최근 수정순, 이 부분만 스크롤), 하단(새 워크플로우 outline · 계정 · 로그아웃) |
| 트리 | 행: 펼침 화살표 · 상태 점 6px(마지막 실행 성공 `--success`, 실패 `--danger`, 실행 중 `--accent`, 없음 `--text-disabled`) · 이름. 이름을 누르면 편집 화면으로 가고 화살표는 펼치기만 한다. 하위 항목(편집 · 실행 기록 + 실행 수 · 설정)은 22px 들여 쓴다. 지금 워크플로우는 펼쳐 둔다 |
| 활성 표시 | `--accent-soft` 바탕 + 500 + `aria-current="page"`. 실행 상세에서는 "실행 기록"이 활성 |
| 접힘 | 아이콘 + 툴팁만. 전역 메뉴와 지금 워크플로우의 하위 항목 3개만 남고 트리는 숨긴다. 선택은 쿠키와 localStorage(`nodeloom.sidebar.collapsed`)에 저장해 새로고침해도 유지한다. **고른 적이 없으면 에디터에서만 접는다**(캔버스 폭) |
| 좁은 화면 | md 미만에서는 숨기고 머리말의 메뉴 버튼으로 왼쪽 드로어(`--scrim` 막)를 연다. 이동하면 닫는다 |
| 높이·포커스 | 모든 항목 32px 이상, 포커스는 `--accent-ring` |
