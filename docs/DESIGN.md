# 디자인 토큰

> 방향: **어두운 작업실형**(디자인 시안 B). 지금은 어두운 테마만 쓴다. 색은 반드시 아래 토큰(CSS 변수)으로만 쓰고 색 값을 코드에 직접 적지 않는다. 그래야 밝은 테마를 나중에 추가할 때 토큰 값만 한 벌 더 정의하면 된다(BACKLOG).

## 색

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--background` | `#0E1116` | 페이지와 캔버스 바탕, 입력 칸 안쪽 |
| `--surface` | `#161B22` | 상단 바, 노드 목록, 설정 패널 |
| `--raised` | `#1C232C` | 노드 카드, 목록 항목, 버튼 |
| `--border` | `#2E3744` | 카드와 입력 칸 테두리 |
| `--divider` | `#262E38` | 영역 사이 구분선 |
| `--grid` | `#252C36` | 캔버스 점 격자 |
| `--foreground` | `#E4E8EE` | 본문 글자 |
| `--muted` | `#93A0AE` | 보조 글자(라벨, 참조 키, 설명) |
| `--disabled` | `#6B7684` | 비활성 글자 |
| `--accent` | `#5FD4C7` | 노드 종류 표시, 선택 테두리, 체크박스, 링크 |
| `--accent-ring` | `rgba(95, 212, 199, 0.18)` | 선택된 노드 바깥 빛 |
| `--edge` | `#3E8F87` | 연결선 |
| `--danger` | `#FF6B6B` | 오류 테두리, 거부된 연결 미리보기 선 |
| `--danger-text` | `#FF9A94` | 오류 글자 |
| `--danger-soft` | `#3A1D20` | 오류 배지 바탕 |
| `--danger-strong` | `#B3302B` | 연결 거부 안내 바탕(흰 글자) |

## 글꼴

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--font-sans` | `'Noto Sans KR', 'Apple SD Gothic Neo', sans-serif` | 본문 전체 |
| `--font-mono` | `'JetBrains Mono', ui-monospace, monospace` | 참조 키, URL, 식, 코드 |

| 크기 | 값 | 쓰는 곳 |
|---|---|---|
| 기본 | 14px | 본문, 입력 칸 |
| 작게 | 12px | 라벨, 설명, 배지 |
| 아주 작게 | 11px | 노드 종류 표시(대문자, 자간 0.06em), 참조 키 |
| 제목 | 16px, 굵게 | 상단 바 제목 |

## 모양과 간격

| 토큰 | 값 |
|---|---|
| `--radius` | 6px (카드, 버튼, 입력 칸) |
| `--radius-pill` | 999px (배지) |
| 캔버스 격자 | 16px |
| 영역 안쪽 여백 | 16px |
| 요소 사이 간격 | 8px(촘촘), 10px, 14px(설정 칸 사이) |
| 버튼·입력 칸 높이 | 최소 36px. 아이콘만 있는 버튼은 44px |
| 노드 카드 | 너비 150px 이상, 안쪽 여백 10px 12px |
| 선택된 노드 | 테두리 2px `--accent` + 바깥 4px `--accent-ring` |
