# M2 에디터

> **상태: 완료 (2026-10-07).** 상위 문서: `docs/PROJECT_PLAN.md` 4절.

## 왜 하나

브라우저에서 노드를 놓고, 잇고, 설정하고, 되돌릴 수 있는 에디터를 만든다. M1의 core 규칙을 화면에 연결하는 단계이고, 저장은 M3에서 한다. 리렌더 최적화는 하지 않고 최적화 전 성능 기준선을 잰다(`docs/PERFORMANCE.md`, 개선은 M9).

## 한 일

에디터 스토어와 커맨드(Undo/Redo), React Flow 캔버스와 팔레트, 노드 종류별 설정 패널, 성능 HUD와 벤치(`/bench`, 새 패키지 `@nodeloom/browser-tests`).

## 만들면서 정한 것

- Zustand 스토어는 에디터마다 새로 만든다(`createStore` + Context). 원본 그래프는 이 스토어에만 두고 React Flow는 제어 모드로 쓴다.
- 커맨드마다 되돌리기(역연산)를 함께 정의한다. 드래그는 놓을 때 시작·끝 위치를 담은 커맨드 하나로 기록하고, 같은 칸을 이어서 입력하면 하나로 합친다.
- 연결은 core `canConnect`를 통과해야만 실행하고, 끄는 동안 포인터 옆에 거부 사유(순환, 중복, 자기 연결, 방향)를 보여 준다.
- 참조 키를 바꾸면 그 키를 쓰던 식은 "없는 참조 키" 오류로 표시한다(자동 수정은 BACKLOG).
- 설정 패널은 폼 라이브러리 없이 스토어를 직접 읽고 쓴다. 설정 칸이 한 화면에 들어가서 Tabs는 넣지 않았다.
